# Week 3 - Menu Routing

## Learning target

Translate numbered user choices into named program actions. This separates input handling from each business operation and prepares the project for a full interactive menu.

## Acceptance checklist

- [x] Four valid menu choices are displayed.
- [x] Each valid choice routes to exactly one named action.
- [x] An invalid choice produces a safe result.
- [x] The routing logic uses a `switch` expression.
