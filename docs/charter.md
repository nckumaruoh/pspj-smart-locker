# Project Charter — Campus Smart-Locker & Parcel Management System

## Purpose

Create a Java application that manages parcel intake, locker allocation, collection and records for a campus community.

## Users

- Delivery staff register incoming parcels.
- Students and employees collect parcels.
- Locker administrators review availability and exceptions.

## Inputs

Parcel ID, recipient details, locker size, parcel weight, arrival time and collection status.

## Processing

Validate parcel data, select an available locker, calculate the storage fee when applicable, update parcel status and persist records.

## Outputs

Intake receipt, locker allocation, collection confirmation, availability summary and activity reports.
